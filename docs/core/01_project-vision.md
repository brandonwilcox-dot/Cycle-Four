# Project Vision

## Game identity
ULBFF V3 is a large-scale RTS built around command hierarchy, battlefield readability, escalation, and persistent military structure.
It should feel like the player commands a real war machine, not a floating bag of individually babysat units.

## Player fantasy
The player is not merely selecting units.
The player is the Ultra Leader, setting strategic intent through subordinate commanders who maintain formations, recruit forces, and carry out objectives at scale.

## Non-negotiables
1. Command hierarchy is core design, not garnish.
2. Groups are persistent simulation structures, not temporary selection artifacts.
3. BattleSim remains authoritative for gameplay truth.
4. The architecture must survive growth to large battles and multiple players.
5. Presentation exists to reveal the war, not secretly run it.

## Design priorities
- battlefield readability
- persistent military identity
- progression through authority and rank
- scalable systems over clever one-off hacks
- clean separation between simulation and presentation
