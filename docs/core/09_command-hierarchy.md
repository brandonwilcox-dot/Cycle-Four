# Command Hierarchy

## Canonical doctrine
Ultra Leader is the player's strategic command unit and root of authority.

Each player may control up to 9 command units total:
- 1 Ultra Leader
- up to 8 top-level commanders

Groups are persistent command structures, not temporary selection results.

Selection is a player interface action only.
It does not define command relationships.

Commanders recruit nearby unassigned units into their structure based on:
- rank
- authority
- mission role
- command capacity
- eligibility rules

Sub-commanders interpret high-level objectives into tactics for their assigned units and subordinate commanders.

Experience earned by subordinate units flows upward through the chain of command to their commander, and ultimately toward the Ultra Leader.

The player manages the hierarchy primarily through the Ultra Leader dashboard and commander interface, not by hand-authoring every local action.

## Rank should influence
- command capacity
- recruitment authority
- formation access
- tactical scope
- progression opportunities

## Future-facing note
Underperforming commanders may later face replacement pressure or vote mechanics, but that layer must not block initial hierarchy implementation.

## Canonical correction rule
If any other document implies that selection creates hierarchy, that other document is wrong and should be corrected.
