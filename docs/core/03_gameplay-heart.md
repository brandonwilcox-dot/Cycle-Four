# Gameplay Heart

## Core loop
1. Start with Ultra Leader and initial command capability.
2. Expand economy and establish base footprint.
3. Construct production structures.
4. Produce units across land, sea, and air domains.
5. Assign or recruit units into persistent command structures.
6. Secure map control and resource advantage.
7. Tech upward through tiers.
8. Field veteran formations under capable commanders.
9. Break stalemates through advanced units and superweapons.
10. Destroy enemy commanders, bases, or satisfy victory conditions.

## Command structure model
Each player may control:
- 1 Ultra Leader
- up to 8 top-level commanders

These commanders:
- persist after selection changes
- recruit and organize subordinate units
- define tactics within player objectives
- gain authority through rank and progression

## Economy and growth
The economy exists to support escalating force structure, map control, and tech progression, not just a bigger unit count.

## Progression
Rank is functional, not cosmetic.
It should influence:
- command capacity
- recruitment authority
- formation access
- tactical scope
- progression opportunities
