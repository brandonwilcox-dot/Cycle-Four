# Production Forge

## Construction model
Support:
- commander or engineer build orders
- blueprint placement
- build progress over time
- resource consumption over time
- completion event promotion

## Production structures
At minimum:
- land factory
- naval factory
- air factory

Each supports:
- unit queue
- rally point
- upgrade path
- production restrictions by tech tier

## Tier model
- Tier 1
- Tier 2
- Tier 3
- Ultimate

## Upgrades and escalation
Factories and strategic structures may upgrade over time to unlock broader production capability and higher-stakes escalation.

## Superweapons
Superweapons should be modeled as first-class simulation systems, not hacks.
